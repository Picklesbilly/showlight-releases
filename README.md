# Showlight releases

Desktop installers for [Showlight](https://getshowlight.com), the stage lighting design app.

Download the latest version from the [Releases page](https://github.com/Picklesbilly/showlight-releases/releases/latest) or from https://getshowlight.com/download.

Each release lists SHA-256 checksums for its files and includes a `SHA256SUMS` file. To check a download:

- macOS: `shasum -a 256 Showlight-<version>-mac-arm64.zip`
- Windows (PowerShell): `Get-FileHash .\Showlight-<version>-win-x64-setup.exe -Algorithm SHA256`

This repository holds release files only; the app's source code is private.
